# 🤖 Robo-Lab Emergency: Git Time Machine & Code Rescue Lab

ยินดีต้อนรับสู่ **Robo-Lab Emergency**! โปรเจกต์ห้องปฏิบัติการหุ่นยนต์ AI สำหรับฝึกฝน **"ทักษะเอาชีวิตรอดและกู้ภัยโค้ดด้วย Git (Git Undo & Time Travel Skills)"**

---

## 🎯 เกี่ยวกับโปรเจกต์นี้

ในชีวิตจริงของการเป็นโปรแกรมเมอร์ เราทุกคนต้องเคยเจอกับสถานการณ์เหล่านี้:
- 😱 *"เผลอกดลบไฟล์ทิ้ง หรือแก้โค้ดจนพังแล้วจำไม่ได้ว่าของเดิมเขียนอะไรไว้!"* -> ใช้ `git restore`
- 🏃 *"โค้ดยังเขียนไม่เสร็จครึ่งๆ กลางๆ แต่มีงานด่วนเข้ามาต้องรีบสลับ branch!"* -> ใช้ `git stash`
- 🗑️ *"เผลอเอาไฟล์ขยะ แคช หรือไฟล์ล็อกส่วนตัวหลุดเข้าไปใน git status!"* -> ใช้ `.gitignore`
- 🕵️ *"เมื่อวานโปรแกรมยังรันได้ดีๆ แต่วันนี้ทำไมหุ่นยนต์เดินเบี้ยว? ใครแก้พัง?"* -> ใช้ `git log -p`
- ✍️ *"พิมพ์ข้อความ commit ผิด หรือลืมใส่ไฟล์แล้วเพิ่งกด commit ไปหมาดๆ!"* -> ใช้ `git commit --amend`

โปรเจกต์นี้จะจำลองสถานการณ์จริง 5 ด่าน ให้นักเรียนได้ลองทำพังจริง และใช้ Git กู้ภัยระบบกลับมาอย่างมืออาชีพ!

## 📁 โครงสร้างโปรเจกต์

```text
git-time-machine/
├── .gitignore               # โล่ป้องกันไฟล์ขยะเข้า Git
├── README.md                # หน้าแนะนำโปรเจกต์
├── STUDENT_LABS.md          # ใบปฏิบัติการ 5 ด่านสำหรับนักเรียน (โจทย์และการทดลอง ไม่มีเฉลย)
├── TEACHER_GUIDE.md         # คู่มือผู้สอนฉบับสมบูรณ์ (บทพูดคำต่อคำ, แผนการสอน 120 นาที, เฉลยทุกด่าน)
├── robo_system/             # โค้ดระบบจำลองหุ่นยนต์ AI (Python)
│   ├── main.py              # โปรแกรมทดสอบความพร้อมของหุ่นยนต์
│   ├── motor_control.py     # โมดูลควบคุมมอเตอร์และการเคลื่อนที่
│   └── sensor_scanner.py    # โมดูลสแกนเนอร์เรดาร์ตรวจจับสิ่งกีดขวาง
└── teacher_assets/          # เครื่องมือและเฉลยสำหรับผู้สอน
```

## 🚀 วิธีรันโปรแกรมระบบหุ่นยนต์

เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์:

```bash
python robo_system/main.py
```
*(ถ้าเครื่องใช้ macOS/Linux แล้วคำสั่ง `python` ไม่ติด ให้ใช้ `python3 robo_system/main.py` แทน)*
